Built to be useful

For the 11pm homework crowd.

MathClass is a network, not a course. There’s no video to sit through and no test at the end — just the class you’re already taking, with more people in it.

  • ✓ Stuck on one line? Paste the step you’re on. Someone has been there this week.
  • ✓ Want to go deeper? Follow the proof threads and contest problems that never made it into class.
  • ✓ Like helping? Answer two questions a week. Explaining is the best revision there is.
